日本心理学会スタイル · BibLaTeX

biblatex-jpa2 使い方ガイドJPA『執筆・投稿の手びき』2022年版準拠スタイル

日本心理学会『執筆・投稿の手びき』（2022年版）の書式で，和文・欧文が混在する引用文献リストを組む BibLaTeX スタイルです。エントリごとに langid を見て和文／欧文の書式を自動で切り替えます。このページは，インストールと .bib の書き方を，文献タイプ別の「入力」と「組版結果」の対で示します。

対象 LuaLaTeX + jlreq backend biber style jpa2 license LPPL

1これは何か

心理学の論文を LaTeX で書く人のためのスタイルです。.bib に文献を貯め、和文には langid = {japanese} を付けるだけで、手びき2022年版の書式（中黒区切りの著者名、全角の年括弧、サブタイトルの ——…——、巻の斜体、DOI のURL化など）で文献リストと本文引用が出力されます。

先行スタイル biblatex-jpa（芝田征司氏）を参考に、言語切替の設計をゼロから作り直したものです。グローバル変数ではなく langid フィールドで一件ずつ判定します。

Word / Zotero を使う人へ

LaTeX ではなく Zotero で同じ書式を使いたい場合は、姉妹プロジェクトの jpa-csl-zotero（Zotero 用 CSL）を使ってください。本スタイルの書式を CSL に移植したものです。

非公式

個人が作成したものであり、日本心理学会が提供・承認したスタイルではありません。

2設置とプリアンブル

スタイルは 5 ファイル（jpa2.bbx / jpa2.cbx / jpa2.dbx / japanese-jpa2.lbx / english-jpa2.lbx）で構成されます。TeX の検索パスに置きます。macOS（MacTeX）なら TEXMFHOME が定番です。

mkdir -p ~/Library/texmf/tex/latex/biblatex-jpa2
cp biblatex/*.bbx biblatex/*.cbx biblatex/*.dbx biblatex/*.lbx \
   ~/Library/texmf/tex/latex/biblatex-jpa2/
kpsewhich jpa2.bbx      # パスが返れば設置成功

プリアンブルは次のとおりです。backend=biber が必須です。

\documentclass[a4paper]{jlreq}
\usepackage[backend=biber, style=jpa2]{biblatex}
\addbibresource{文献.bib}

\begin{document}
本文中の引用は \textcite{Fukaya2011a} や \parencite{Sugiura2003} で。
\printbibliography[title=引用文献]
\end{document}

ビルドは lualatex → biber → lualatex の順です。biblatex 3.17 以降・biber 2.17 以降を推奨します。

3最初に必ず、この2つ

① 和文には langid = {japanese}

これが和文書式のスイッチです。欧文文献には付けません（既定で欧文として処理）。既存の .bib で language = {japanese} を使っている場合も、biber の sourcemap が自動で langid に変換します。

② 和文には sortname と sorttitle

手びきの並び順は、和文・欧文を区別せずローマ字読みで混在ソートします（浅野=Asano が American と Christie の間に入る）。CSL/biber は漢字の読みを知らないので、読みを与えます。

  • sortname: 著者名のローマ字（例 Fukaya, Tatsushi）— 欧文と混ざる並び順を決める
  • sorttitle: タイトルのひらがな読み（例 かがくてきがいねん…）— 同一著者・同一年の a/b（extradate）の順序を決める

sorttitle をひらがなにすると、biber が Unicode の五十音順（か < が < き …）で正しく extradate を振ります。

6翻訳書は2エントリで連結する

翻訳書は、原著の欧文エントリと訳書の和文エントリを別々に作り、訳書側から related / relatedtype = {translationof} で原著を指します。原著の後ろに訳書を全角括弧で並記する手びきの形が自動生成されます。

訳書（related 方式）
.bib 入力
@book{LopezCorvo2009,
  author    = {Lopez-Corvo, R. E.},
  date      = {2009},
  title     = {The Woman Within},
  subtitle  = {A Psychoanalytic Essay on Femininity},
  publisher = {Routledge},
}
@book{LopezCorvo2014ja,
  author          = {ロペス＝コルヴォ, R. E.},
  sortname        = {Lopez-Corvo, R. E.},
  translator      = {井上, 果子},
  translatortype  = {監訳},
  translatora     = {飯野, 晴子 and 赤木, 里奈
                     and 山田, 一子},
  translatoratype = {訳},
  date            = {2014},
  title           = {内なる女性},
  subtitle        = {女性性に関する精神分析的小論},
  publisher       = {星和書店},
  related         = {LopezCorvo2009},
  relatedtype     = {translationof},
  langid          = {japanese},
}
組版結果
Lopez-Corvo, R. E. (2009). The Woman Within: A Psychoanalytic Essay on Femininity. Routledge. (ロペス＝コルヴォ R. E. 井上 果子 （監訳） 飯野 晴子・赤木 里奈・山田 一子 （訳） （2014）．内なる女性——女性性に関する精神分析的小論——　星和書店)

本文引用は \textcite{LopezCorvo2014ja} で「Lopez-Corvo （2009 井上監訳 2014）」のように、原著年と訳書年を併記します。

7スタイルが自動でやること

  • 言語切替：langid を見て、著者区切り（・ / ,&）・年括弧（全角／半角）・句読点・スペースを一件ずつ切り替える。
  • 後方互換：language = {japanese} を langid に自動変換する。
  • 3名以上の引用：本文では「第1著者 他（発行年）」に短縮する（他 / et al.）。
  • 混在ソート：sortname のローマ字で和文・欧文を一列に並べる。
  • 翻訳書：related でつないだ原著＋訳書を1項目にまとめる。

8よくある失敗と直し方

Style 'jpa2' not found. と出る

スタイルをシンボリックリンクで置いています。コピーで設置し直してください。原稿フォルダにローカルコピーを置く運用でも解決します（カレントディレクトリが優先されます）。

3名の引用が「第1著者・第2著者 他」になる

基底スタイルの uniquelist が名前リストを展開しているためです。手びきは「第1著者 他（年で区別）」なので、jpa2.cbx 側で uniquelist=false, uniquename=false を明示済みです（v0.3 で対応）。古い版を使っている場合は最新に更新してください。

DOI が出力されない

@misc 駆動子は DOI を出しません。R パッケージなど DOI を出したい資料は @software や @online を使ってください。

a/b の順序が手びきと違う

同一著者・同一年の並びは sorttitle（ひらがな読み）で決まります。sorttitle を付けると Unicode 五十音順で正しく振られます。

9対応エントリタイプ

エントリタイプ用途
@article雑誌論文・紀要・Advance online publication
@book書籍（一般・版数・編集書）
@inbook編集書中の特定章
@incollection数巻シリーズの特定の1巻
@mvbook数巻にわたる書籍
@onlineプレプリント・ウェブ資料
@thesis学位論文
@inproceedings学会発表
@report年報・年鑑
@softwareソフトウェア（DOI 出力可）
@misc新聞・雑誌記事

手びき2022年版の見本3.8・セクション3.10 の全引用例を doc/sample.bib に収録し、doc/jpa2-manual.pdf で出力を確認できます。
